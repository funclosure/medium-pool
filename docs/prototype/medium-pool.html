Mediums

One skill each. A lane is a folder. A kind is a data domain inside a lane whose concerns diverge; it is a folder too, named lane-kind, and shows up under its lane.

Compositions

Two or more mediums bound together. The skill teaches the binding and points at the mediums for the parts.

How the repo will be laid out

      
Each demo above is the reference implementation its skill points to. The site imports the same file the agent reads, so the skill is proven by the running demo. Every lane is a folder with a small manifest, and the site discovers folders at build time, so extending the pool never touches site code.

      
“The medium is the message” is Marshall McLuhan, Understanding Media (1964). Here it is a design lens: every lane names what the medium does to a person before any content arrives, and the skills lead with that.
